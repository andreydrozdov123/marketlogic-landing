# MARKETLOGIC — лендинг обучающего форекс-оффера

Статическая посадочная страница (HTML/CSS/JS, без сборки).

- `index.html` — разметка и весь контент
- `styles.css` — стили, mobile-first
- `script.js` — меню, аккордеон программы, анимации появления, валидация формы

## Что поменять под себя
- Название бренда: поиск `MARKETLOGIC` в `index.html`
- Имя автора и фото: секция `#author` (сейчас плейсхолдер «Фото»)
- Отправка формы: `script.js`, комментарий `TODO` в обработчике submit
- Акцентный цвет: `--accent` в `styles.css`
