# MARKETLOGIC — лендинг обучающего курса по трейдингу

Статическая страница (HTML/CSS/JS, без сборки). Стилистика — светлый EdTech по мотивам Skillbox.

- `index.html` — разметка и весь текст
- `styles.css` — стили, mobile-first
- `script.js` — меню, аккордеон программы, появление блоков, валидация формы
- `img/` — сюда класть картинки

## Как вставить свои картинки

В HTML на местах картинок стоят серые пунктирные блоки `<figure class="ph …">`.
Над каждым — комментарий с готовой строкой замены. Порядок:

1. положить файл в `img/`
2. удалить весь блок `<figure class="ph …">…</figure>`
3. на его место поставить `<img src="img/имя.jpg" alt="описание">`

Список слотов и размеров:

| Слот | Файл | Размер | Что нужно |
|---|---|---|---|
| Первый экран | `img/hero.jpg` | 1200 × 1400 | автор / рабочее место с графиками, вертикальное |
| Практика 1 | `img/practice-1.jpg` | 800 × 600 | скрин графика с разметкой уровней |
| Практика 2 | `img/practice-2.jpg` | 800 × 600 | расчёт риска / калькулятор позиции |
| Практика 3 | `img/practice-3.jpg` | 800 × 600 | терминал с открытой сделкой |
| Индиго-блок | `img/claim.jpg` | 1000 × 700 | кадр из урока, разбор сделки |
| Формат 1 | `img/format-1.jpg` | 1200 × 700 | скрин платформы / список уроков |
| Формат 2 | `img/format-2.jpg` | 1200 × 700 | обратная связь, разбор в чате |
| Автор | `img/author.jpg` | 1000 × 1250 | портрет, вертикальное |
